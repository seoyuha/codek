# CODE K : 전통문화 비밀요원

6학년 영어 11단원(Do You Know About Songpyeon?) 복습용 **코드네임 방식 온라인 팀 게임**입니다.
교사가 교실을 만들면 학생들이 **6자리 교실 코드**로 들어오고, 모둠 자동 배정 → 전체 시작 → 판이 끝나면 역할을 바꿔 자동으로 다음 판이 이어집니다.

## 폴더 구성

```
codek/
├─ server.js            게임 서버 (교실·모둠·규칙·점수·AI)
├─ data/units.js        단원 데이터 (카드 28장, 힌트 단어 40개, 문장)
├─ package.json
└─ public/
   ├─ index.html        학생·교사 화면 (한 파일)
   ├─ fonts/            게임 글꼴 (Noto Sans KR, 검은고딕 — 무료 글꼴)
   └─ assets/
      ├─ theme/         화면 디자인 (시안 그림을 게임용으로 정리한 배경·아바타·엠블럼)
      └─ cards/         카드 사진 28장 (가로 3:2)
```

## 화면 디자인 (CODE K 시안 적용)

시안 8장을 그대로 화면 배경으로 쓰고, 그림에 그려진 버튼 위에 진짜 버튼을 겹쳐 두었습니다.
시안에 있던 가짜 이름·점수·문구는 지우고 실제 게임 정보가 그 자리에 나옵니다.

## GitHub + Render 배포

1. GitHub에 새 저장소(예: `codek`)를 만들고 이 폴더 안의 파일을 모두 올립니다. (`node_modules`는 올리지 않아도 됩니다)
2. Render → **New → Web Service** → 저장소 연결
   - Build Command: `npm install`
   - Start Command: `npm start`
3. 배포가 끝나면 나오는 주소를 학생들에게 알려 주면 됩니다.

> Render 무료 요금제는 한동안 접속이 없으면 잠들었다가 첫 접속 때 30초쯤 걸려 깨어납니다. 수업 직전에 교사 화면을 한 번 열어 두세요.
> 서버가 다시 시작되면 교실·점수가 초기화됩니다.

## 게임 규칙 요약

- 모둠(4~6명)이 빨강·파랑 팀으로 나뉘고, 팀마다 힌트 담당 1명 + 요원.
- 판 하나에 카드 20장: 먼저 시작한 팀 7장, 다른 팀 6장, 마을 사람 6장, 도깨비 1장.
- 힌트 담당은 카드 색을 보고 **영어 힌트 단어 + 숫자**를 보냄 (예: FOOD 2). 힌트 단어는 목록에서 고르므로 엉뚱한 말이 나오지 않음.
- 요원은 카드를 눌러 투표 → 팀 요원 과반(2명 이하면 1명)이 같은 카드를 누르면 열림. 숫자 + 1장까지 고를 수 있음.
- 카드가 열리면 "Do you know about ~?"와 설명 문장을 원어민 음성으로 읽어 줌.
- 인원이 부족한 팀(모둠 2~3명)은 AI가 힌트 담당이나 요원을 대신 맡음. 학생이 나가거나 시간이 지나도 AI가 이어 줌.
- 점수: 맞힌 카드 +10(투표한 요원), 힌트 담당 +5, 승리 +30, 참가 +5.

## 교사 화면

- 단원·모둠 인원·턴 시간(60/90/120/180초/제한 없음)·힌트 한글 뜻 보이기·자동 다음 판 설정
- 🎲 모둠 자동 배정 / ▶ 전체 게임 시작 / ⏭ 모든 모둠 새 판 / 🏁 게임 끝내기·순위 발표 / 랭킹 초기화 / 학생 내보내기
- 모둠별 게임판(정답 색 포함)·차례·힌트를 실시간으로 볼 수 있음
- 게임 중에 늦게 들어온 학생은 인원이 가장 적은 모둠에 자동으로 들어감

## 새 단원 추가

`data/units.js`에서 `'11': {...}`과 같은 모양으로 `'12': {...}`를 추가하면 교사 화면 단원 목록에 나타납니다. 카드는 20장 이상 필요합니다.

## 배경음악·효과음 (assets/sound)

CODE K 오리지널 사운드(배경음악 4곡, 효과음 17종)를 mp3로 바꿔 넣었습니다. 수업용으로 잔잔하게 맞춰 두었어요.
- 음량: 배경음악 10%, 효과음 30% (index.html의 `VOL` 값으로 조절)
- 원어민 문장을 읽어 줄 때는 배경음악이 잠깐 더 작아져요.
- 배경음악: 시작·입장 화면 / 대기실 / 게임 진행 / 결과·순위 화면마다 바뀜
- 효과음: 버튼, 코드 확인, 입장, 게임 시작, 카드 선택, 파란·빨간·마을 사람 카드 공개, 힌트 공개, 차례 알림, 10초 경고, 도깨비, 승리, 패배, 다음 판 카운트다운
- 설정(⚙)에서 "배경음악 끄기"만 따로 할 수 있고, 🔊 버튼은 모든 소리를 끄고 켭니다.
- 브라우저 규칙 때문에 화면을 한 번 터치한 뒤부터 소리가 나요.
